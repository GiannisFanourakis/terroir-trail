# Phase 13 — Greek Cheese & Dairy Expansion: Stage 2 Audit

Date: 2026-09-16
Owner approval of shortlist: confirmed 2026-09-16

## Scope

The project owner approved the locked Phase 13 shortlist of 16 new dairy/cheese producers. This document records the second-stage evidence audit before any Supabase import or public publication.

This is still **not** a publication list. A candidate can pass identity/product/contact checks while remaining blocked on exact mapped point, public visitor procedure, road evidence, or Google Place identity.

## Audit rules

For every producer, keep these facts separate:

1. producer identity;
2. production-site identity/location;
3. product and PDO/PGI claims;
4. public visitability;
5. mapped public-point role;
6. road/access evidence;
7. producer-controlled contact channels;
8. Google Place identity where Google imagery will be used.

A shop, office, cooperative headquarters, village centre, or reseller must never silently replace the production site. A published address does not automatically mean public visits. A Google pin does not establish road safety.

No candidate currently has sufficiently explicit source-backed road-surface, width or normal-rental-car suitability evidence for TerroirTrail to publish a road classification. All remain `not_publicly_confirmed` until a separate road audit resolves them.

### Next gate before import

Before any producer is inserted into Supabase or added to the bundled fallback catalogue:

1. manually resolve exact production/public map point;
2. confirm mapped-point role (`production_site`, `producer_shop`, etc.);
3. capture Google Place ID where applicable;
4. assign conservative visit status from explicit evidence;
5. keep road access unclassified unless independently supported;
6. verify PDO/PGI claims at producer/certification level where the listing will state them explicitly;
7. prepare source-backed story, tagline and product-specialty fields;
8. run duplicate/entity collision checks against the live catalogue.

No Phase 13 candidate is authorized for public import merely by this audit document.
