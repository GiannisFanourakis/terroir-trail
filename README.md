## 🌟 Vision & Mediterranean Terroir Scope

While mass tourism concentrates in coastal resort bubbles, discerning travelers, culinary explorers, and road-trippers rent cars and venture into the rural hinterlands seeking **authentic, independent, family-run craft makers**:

* 🍇 **Indigenous & Biodynamic Wineries:** Single-vineyard Vidiano, Liatiko, Romeiko, Assyrtiko, Agiorgitiko, Xinomavro, and Sangiovese Grosso; natural fermentations, amphora aging, and ancient bush-vine heritage.
* 🍺 **Local Craft Microbreweries:** Independent, unpasteurized ales, IPAs, and fresh mountain lagers brewed with pure mountain runoff, wild Mediterranean botanicals, and volcanic stone filtration.
* 🏺 **Traditional Rakokazana:** Wood-fired copper alembic stills producing small-batch, artisanal Tsikoudia / Raki during autumn harvest gatherings with live village mezedes.
* 🫒 **Artisan Olive Mills & Ancient Groves:** Cold-pressed extra virgin olive oil from millenary Tsounati and Koroneiki groves using traditional granite millstones and hydraulic presses.
* 🧀 **Mountain Shepherd Mitata & Dairies:** Raw-milk Graviera, Pichtogalo, and Anthotyros hand-crafted in stone alpine huts (*mitata*) and remote mountain valleys.
* 🍯 **Wild Herb Foragers & Apiaries:** Rare single-origin mountain thyme honeys and wild foraged Malotira (Cretan mountain tea), Diktamos, and wild mountain oregano.

### Curated Macro Regions (58 Hand-Vetted Producers)

1. **Crete:** Chania (Kissamos, Apokoronas, Platanias), Rethymno (Amari Valley, Spili), Heraklion (Archanes, Peza, Malevizi), and Lasithi (Sitia, Mirabello).
2. **Santorini:** Volcanic micro-terroirs of Mesa Gonia, Pyrgos Kallistis, Megalochori, and Oia (*Kouloura* basket vine training).
3. **Peloponnese:** Legendary red terroirs of PDO Nemea (*Blood of Hercules* Agiorgitiko), high-altitude Mantineia (Moschofilero), and Aigialeia slopes.
4. **Northern Greece:** Historic PDO Naoussa and Amyndeo (single-vineyard Xinomavro, indigenous mountain viticulture).
5. **Tuscany (Italy):** Renowned European benchmark terroir encompassing Chianti Classico (Radda, Gaiole, Castellina), Brunello di Montalcino, Vino Nobile di Montepulciano, and the Val d'Orcia.

## 🏛️ Data Provenance & Verification

Every maker profile, coordinates point, grape variety, and tasting package in TerroirTrail is curated and verified against official viticultural, brewing, and agricultural registries:

1. **Wineries & Appellations:**
   * **Wines of Crete (`winesofcrete.gr`):** Certified member estates across Crete (e.g. Manousakis, Dourakis, Lyrarakis, Domaine Paterianakis, Silva Daskalaki, Iliana Malihin, Klados, Karavitakis).
   * **Wines of Greece & Regional Associations:** Peloponnese Winemakers Association (*ENOAP* - Nemea), Northern Greece Winemakers (*ENOABE* - Naoussa, Amyndeo), and the PDO Santorini volcanic viticulture registry (Santo Wines, Domaine Sigalas, Vassaltis Vineyards, Estate Argyros).
   * **Consorzio Vino Chianti Classico & Consorzio del Vino Brunello di Montalcino:** Certified historic Italian DOCG estates (Monteraponi, Antinori nel Chianti Classico, Biondi-Santi, Fontodi, Castello di Ama).
   * **PDO / PGI Designations:** Formally protected native varieties (Vidiano, Mandilaria, Vilana, Romeiko, Assyrtiko, Agiorgitiko, Xinomavro, Sangiovese).

2. **Craft Microbreweries:**
   * **Cretan Brewery (Charma):** First independent microbrewery in Crete (Zounaki, Chania), featuring open-air brewhouse taprooms and fresh unpasteurized tank beer.
   * **Solo Craft Brewery:** Internationally acclaimed craft brewer based in Heraklion, known for unfiltered, non-conformist ales (*Fourtouna*, *Psaki*).
   * **Lafkas Brewery:** Artisanal Greek-Belgian brewery in Chania brewing with White Mountains spring water and raw Cretan grains (*White Mountains Triple*).
   * **Santorini Brewing Company:** Volcanic craft microbrewery in Mesa Gonia (*Yellow Donkey*, *Red Donkey*, *Crazy Donkey*).

3. **Traditional Distilleries, Olive Mills & Dairies:**
   * Traditional village *kazanaris* distillation permits (custom autumn Tsikoudia distillation in Zaros, Spili, and Amari).
   * Certified organic single-estate olive oil producers (Biolea Astrikas traditional granite mill & hydraulic press, Anoskeli, Terra Creta, Sitia PDO estates).
   * High-mountain cheese mitata following Protected Designation of Origin standards (Graviera Kritis PDO, Pichtogalo Chanion PDO).

4. **Road Accessibility & Precision GPS:**
   * Verified decimal coordinates matched against OpenStreetMap, satellite imagery, and topography to prevent travelers from getting stranded on dangerous goat trails.
   * Road access classification:
     * 🟢 **Smooth Asphalt:** Standard small rental cars welcome.
     * 🟡 **Compact Gravel:** Standard car manageable at cautious speeds.
     * 🔴 **High Mountain Dirt Track:** High-clearance SUV or 4x4 strictly recommended.

## 📷 Media Architecture & Transparent Attribution

TerroirTrail uses a **Zero-Risk, High-Performance Media Architecture**:

* **100% Self-Contained Local Asset Bundling:** All estate imagery is hosted locally in `public/images/estates/`. This completely eliminates live third-party Google Places API calls, preventing unexpected billing charges, API quota limits, and Google Maps Platform Terms of Service constraints.
* **Verified Creative Commons & Archival Press Licenses:** Media assets are sourced from verified Creative Commons photographers (CC-BY, CC-BY-SA, CC0) on Wikimedia Commons and official producer media press kits.
* **Explicit In-App Attribution:** The application models photo rights in `src/types/terroir.ts` (`PhotoCredit`):
  * **Photographer / Author Name**
  * **License Type** (e.g., CC-BY-SA 4.0, CC-BY 3.0, Estate Press Kit)
  * **Canonical Source URL**
* **UI Badge Integration:** Visible photo credits are rendered as an elegant hero overlay chip and an attribution footer inside the maker's detail drawer, ensuring artists and estates receive full credit.

## 💡 Monetization & Fair-Trade Agritourism Engine

TerroirTrail balances traveler savings with a fair-trade, sustainable economic model for rural producers:

### 1. 👑 Terroir Holiday Pass (€14.99 / 14-Day Trip Access)
Designed for vacationers and culinary tourists exploring wine regions:
* **Complimentary Welcome Pours:** Library or cellar-reserve pour at 20+ participating boutique estates.
* **Free Artisan Meze Pairings:** Complimentary sheep graviera cheese, rusks, and organic olive pairings with every booked tasting.
* **10% Cellar-Door Bottle Discount:** Direct 10% savings on wine, beer, and olive oil bottle purchases to take home.
* **€30 Chauffeur Voucher & €15 Wine Box Voucher:** Instant credit towards private transit or temperature-controlled international shipping.
* **Digital Holographic Wallet Pass:** Apple Wallet and Google Wallet compatible pass with instant QR verification for cellar masters.

### 2. 🛡️ Producer Portal & Verified Host Pro (€39/mo or €19.99/yr)
Empowers independent artisans to take control of their digital presence:
* **0% Commission Agritourism:** While major online travel agencies (OTAs like TripAdvisor, Viator, and GetYourGuide) take **20% to 25% commissions** on every tasting, TerroirTrail charges **0% booking commission**, keeping 100% of tasting revenue in the hands of the producer.
* **Claim Listing & Live Cellar Bulletin:** Estates can publish real-time notices on the interactive map (e.g., *"Harvest in progress: barrel room walk-ins welcome today"*, *"Grape stomp dinner Friday"*).
* **Direct Bottle Shop Link:** 0% commission direct link button on the producer drawer steering travelers directly to the estate's own online cellar shop.
* **Verified Gold Badge:** Glowing gold border and icon on the interactive map with featured priority in Day-Trip Circuits.
* **Visitor Analytics:** Live breakdown of visitor origins (Germany, UK, USA, France) and reservation volumes.

### 3. 📦 "Taste of the Trail" Curated Wine Boxes
* Certified temperature-controlled shipping of authentic small-batch wines and olive oils across the EU, UK, and US.
* Direct cellar collaborations bundling rare indigenous varieties (Vidiano, Liatiko, Xinomavro, Chianti Classico Riserva) with sommelier tasting guides.

### 4. 🚐 Private Mercedes Chauffeur Wine Circuits
* On-demand private chauffeur options for winding mountain wine roads.
* Eliminates the risk of drink-driving on narrow mountain serpentines, allowing visitors to enjoy wine tastings and distillery visits safely.

## 🛠️ Hybrid Cloud & Architecture

TerroirTrail is built with an **Offline-First, Cloud-Synced Hybrid Architecture**:

```
                                 ┌─────────────────────────────────┐
                                 │       React 19 Frontend         │
                                 │   (Vite + Tailwind CSS v4)      │
                                 └──────────────┬──────────────────┘
                                                │
                 ┌──────────────────────────────┴──────────────────────────────┐
                 ▼                                                             ▼
  ┌──────────────────────────────┐                              ┌──────────────────────────────┐
  │     Supabase PostgreSQL      │                              │      Firebase Services       │
  │     + PostGIS Geospatial     │                              │   (Auth + Cloud Firestore)   │
  ├──────────────────────────────┤                              ├──────────────────────────────┤
  │ • Spatial producer queries   │                              │ • OAuth (Google, Apple)      │
  │ • Viewport bounding boxes    │                              │ • Traveler profiles          │
  │ • Structured tasting flights │                              │ • Digital passport stamps    │
  │ • Auto-fallback to offline   │                              │ • Private tasting notes      │
  │   bundled static dataset     │                              │ • Real-time bookings sync    │
  └──────────────────────────────┘                              └──────────────────────────────┘
```

* **Frontend:** React 19, TypeScript, Vite 8, Tailwind CSS v4.
* **Mapping Engine:** Leaflet, OpenStreetMap, CartoDB, Esri Satellite.
* **Geospatial & Relational Data:** Supabase PostgreSQL with PostGIS extension (`src/services/supabase.ts`, `src/services/producerService.ts`).
* **Authentication & Real-Time Sync:** Firebase Auth + Cloud Firestore (`src/services/firebase.ts`).
* **Resilient Offline Fallback:** If cloud credentials (`VITE_SUPABASE_*` or `VITE_FIREBASE_*`) are not provided, TerroirTrail automatically and seamlessly falls back to bundled static datasets (`src/data/producers.ts`) and browser `localStorage`.

## 💻 Getting Started Locally

### Prerequisites
* **Node.js**: `v18.0.0` or higher
* **npm** or **yarn** / **pnpm**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/GiannisFanourakis/terroir-trail.git

# 2. Navigate into the project root
cd terroir-trail

# 3. Install dependencies
npm install

# 4. Start the local Vite development server
npm run dev
```

Visit `http://localhost:5173` in your browser. The app runs completely self-contained out-of-the-box with zero initial configuration required!

### Optional Environment Variables (`.env.local`)

To connect live Supabase or Firebase backends:

```env
# Supabase (Geospatial PostgreSQL Database)
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key

# Firebase (Authentication & Real-Time Sync)
VITE_FIREBASE_API_KEY=your-firebase-api-key
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your-project-id
VITE_FIREBASE_STORAGE_BUCKET=your-project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your-sender-id
VITE_FIREBASE_APP_ID=your-app-id
```

### Build & Production Preview

```bash
# Run TypeScript type check and compile Vite bundle
npm run build

# Preview production build locally
npm run preview
```
